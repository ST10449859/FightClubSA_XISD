# FightClubSA_XISD

A PHP/MySQL prototype for the FightClubSA Booking and Membership Management System.

## Folder structure
- `Index.php` - home page
- `login.php` - member login prototype
- `register.php` - member registration
- `catalog.php` - class catalogue
- `product.php` - class details and booking
- `product-details.php` - class-details compatibility page
- `cart.php` - member bookings
- `config/database.php` - MySQL connection
- `database.sql` - database/tables/sample data
- `assets/css/style.css` - styling
- `assets/js/main.js` - client-side interactions
- `mobile/index.html` - mobile application prototype
- `docs/` - reserved for project documentation

## Run with XAMPP
1. Copy the `FightClubSA_XISD` folder to `C:\xampp\htdocs\`.
2. Start Apache and MySQL in XAMPP.
3. Open phpMyAdmin and import `database.sql`.
4. Visit `http://localhost/FightClubSA_XISD/Index.php`.
5. For the mobile prototype, visit `http://localhost/FightClubSA_XISD/mobile/`.
